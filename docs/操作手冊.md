# RenoCare 宅匠 操作手冊

這份文件回答一件事：**東西要從哪裡輸入、按哪個按鈕、然後會發生什麼。**

系統為什麼這樣設計，看 [`產業痛點對照.md`](產業痛點對照.md)；
有哪些功能，看 [`../功能介紹.md`](../功能介紹.md)。

> 每一頁畫面上方都有一個「**? 操作說明**」可以展開，寫的是那一頁的步驟與名詞。
> 這份手冊補的是**跨頁面的流程**——一個案子從接到結，中間要經過哪幾頁。

---

## 第一次使用：上線前先做完這五件事

順序不能顛倒，後面的東西會用到前面的設定。

### 1. 系統設定（系統 → 系統設定）

先把下拉選單改成貴公司實際在用的字，之後每一張單都從這裡帶。

| 欄位 | 填什麼 | 影響到哪裡 |
| --- | --- | --- |
| 公司名稱 | 貴公司抬頭 | 側欄、列印出來的每一張文件、業主端 |
| 工種 | 拆除、泥作、木作、水電、油漆… | 發包單、工序、工班分類、雜支 |
| 案場類型／風格 | 新成屋、中古屋、辦公室… | 新增案場時的下拉 |
| 雜支科目 | 規費、吊車、垃圾清運、保險… | 專案雜支；也是成本結構下鑽的分組依據 |
| 收付款方式 | 現金、匯款、支票… | 登錄收款與付款 |
| 許可申辦項目 | 室內裝修審查、消防圖說、竣工查驗… | 許可與法規 |
| 客戶來源 | 舊客介紹、網路、建商合作… | 客戶名單；日後要知道案子從哪來 |

**請款節點範本**：格式「名稱:百分比」，逗號分隔。例：
`訂金:30,開工款:30,木作進場:20,完工驗收:15,交屋尾款:5`
新案子按「套用範本」就會一次帶進來，不必每個案子重打。

**工序範本**：格式「名稱:工種:天數:與前一項的間隔天數」，逗號分隔。
系統會依序把前後相依關係串好，之後某一道延誤，後面會自動一起推。

**預設值**：發包保留款％、保固金％、保固月數、提醒提前天數。

**契約與代扣**：遲延違約金（每日千分之幾、上限％）、個人工班代扣所得稅％與門檻、二代健保補充保費率與門檻。
預設值依內政部室內裝修契約範本與現行執行業務所得規定，法規調整時改這裡即可。
提醒提前天數同時是「開單請款沒填期限時的收款帳期」。

### 2. 建立帳號（系統 → 帳號權限）

一人一個帳號，不要共用——共用的話操作紀錄就失去意義。

- **角色**只有兩種：管理員（全部模組）、員工（逐一勾選模組）。
- 勾完模組之後，還可以在「其中只能看不能改」再勾一次：那個模組變成唯讀。
  典型用法：讓工務看得到發包單（要知道叫誰來），但改不了金額。
- 帳號做過事之後就刪不掉了，只能停用——刪掉會讓歷史紀錄變成無名氏。

建議的權限分配：

| 角色 | 給哪些模組 | 不要給 |
| --- | --- | --- |
| 負責人 | 全部（設成管理員） | — |
| 設計師 | 客戶、估價單、案場、追加減帳、請款收款、圖面、許可、缺失、保固 | 應付與押款、帳號權限 |
| 工務／監工 | 案場、工進、日報照片、發包估驗、建材、缺失、工班 | 專案損益、估價單、應收帳款 |
| 會計／行政 | 請款收款、應收帳款、應付與押款、專案損益 | 估價單、發包（避免動到金額） |

### 3. 工項單價庫（接案 → 工項單價庫）

這是報價的公版。每一項都有**對客報價**與**成本**兩組數字，材料與工資分開。
先把常做的三十到五十項建起來，之後開估價單用勾的就好，不必每次重打。

沒有這一步也能開估價單（可以手動一行一行加），但每張單都要重打，
而且成本欄容易忘了填——成本沒填，這個案子的毛利就是假的。

### 4. 工班與廠商（發包 → 工班與廠商）

把配合的工班與材料商建起來。**責任險到期日一定要填**——
保險過期的工班還在現場施工，出事責任會回到公司身上，系統會在清單上標紅。

### 5. 匯入現有案子（選）

已經在跑的案子也可以放進來：新增案場 → 手動新增一張合約（不必走估價單）→
套用請款節點範本後調整比例 → 已經收過的款用「登錄收款」補登。
工進與發包可以只建還沒做完的部分。

## 每一頁都一樣的基本操作

每一頁上方都有「**? 操作說明**」，點開就是那一頁的步驟，看不懂先點它。

**清單頁**（客戶名單、案場專案、估價單、工項單價庫、追加減帳、工班與廠商、建材訂料、
缺失與驗收、保固維修、許可與法規、我的工作、全部待辦、帳號權限）：

| 要做的事 | 怎麼做 |
| --- | --- |
| 新增 | 清單上方的「新增○○」按鈕 |
| 編輯 | 每一列右邊的「編輯」 |
| 刪除 | 每一列右邊的「刪除」，會先跟你確認。已經牽涉到錢或軌跡的資料刪不掉（例如有案場的客戶、有估驗的發包單），畫面會說原因 |
| 搜尋 | 上方「搜尋」欄打關鍵字，按 Enter 或點別處就會套用 |
| 篩選 | 上方的下拉選單（狀態、案場、工種、來源…），選了立刻套用 |
| 匯出 | 「匯出 CSV」匯出的是篩選後畫面上的資料 |

**選案場的頁面**（工進排程、工地日報與照片、發包與估驗、請款與收款、圖面與許可）：
先在最左邊選案場，右邊的篩選欄位只縮小這個案子底下的清單。
套用篩選時上方會出現「已套用篩選」的提示，**金額合計仍然是全案**；按「清除篩選」回到完整清單。

**案場裡的明細**也都可以改：收款紀錄、變更明細（簽認前）、發包明細、估驗（最後一期且未付款）、
圖面資訊、工地日報、照片資訊、訂料、缺失、保固、許可、雜支，每一列都有「編輯」與「刪除」。

**我的工作／全部待辦**（每日作業）：
- 「我的工作」只列指派給你、還沒做完的事；「全部待辦」看全公司，可以再依負責人篩選。
- 按「**新增工作**」：填標題、到期日，可以指派給別人並綁到案場。
- 做完按「**完成**」；內容要改按「編輯」，不需要了按「刪除」。
- 標「自動」的是系統每天產生的提醒（見下方「系統每天自己會做的事」），處理完按完成，同一件事不會重複跳出來。
- 預設只列未完成的；要看做完的，把「狀態」改成「已完成」。

## 一個案子從頭到尾

以下每一段都標了**在哪一頁**、**誰做**、**做完會發生什麼**。

### 階段一：接洽與報價

**1. 建客戶**（接案 → 客戶名單 → 新增客戶）
姓名、電話、來源。統編與地址可以之後補。

**2. 開案場**（每日作業 → 案場專案 → 新增案場）
案名、客戶、地址、坪數、設計師、狀態選「洽談中」。
**坪數要填**——沒有坪數就算不出每坪利潤，那是判斷案子該不該接最有用的數字。

**3. 開估價單**（接案 → 估價單 → 新增估價單）
選案場 → 進去之後按「從單價庫帶入」勾工項，或「新增一行」手動加。
每一行有對客單價與成本單價兩欄，成本欄請確實填——右上角的「預估毛利」就是靠它。

**4. 送客戶**：按「列印報價單」印出來或存成 PDF。
**紙上不會出現成本與毛利**，可以直接交給客戶。

**5. 客戶要改**：按「開新版本」。系統會複製上一版的所有明細，改兩行就好，
舊版自動標成「已被新版取代」但留著——日後爭議翻得出當時報的是哪一版。

**6. 成交**：按「標為已成交」。系統會自動：
- 產生一張合約（金額 = 這一版的報價總額）
- 把案場狀態推進到「已簽約」
- 鎖住這張估價單不能再改（要調整只能走追加減帳）

### 階段二：簽約後的前置作業

**7. 排請款節點**（案場詳情 → 合約與收款分頁 → 請款節點 → 套用範本）
套完之後依實際合約調整。**節點比例加起來要等於合約金額**——
少了一段，頁面上會直接告訴你少多少，不要等到尾款才發現漏了。
預設範本依內政部《建築物室內裝修－工程承攬契約書範本》的上限：
**簽約金 5%、水電完成 25%、木作完成 30%、完工清潔 30%、驗收交屋 10%**。
第一期超過 5% 或單期超過 30% 時頁面會提醒——範本不是強制規定，但跟業主有爭議時常被拿來對照；
尾款在驗收並取得**室內裝修合格證明**後才收。

**8. 排工進**（案場詳情 → 工進分頁 → 套用範本，或逐道新增）
每道工序填預計開工與完工日。工序之間有前後相依，改一處後面會自動推。

**9. 把請款節點綁到工序**（編輯節點 → 對應工序 → 選「開工時」或「完成時」）
綁了之後，那道工序一開工，節點隔天自動從「未到」變成「可請款」，
並且開一張待辦提醒你去開單。**這是防止「做到了忘記請款」最有效的一步。**

**工期遲延違約金**：合約完工日過了還沒填實際完工日，案場詳情上方會顯示業主可以主張的違約金。
合約有填「逾期違約金／日」就照合約；沒填就依範本每逾 1 日課合約總價**千分之一**，總額以**合約總價 10%** 為限。
這是風險提示，不會扣進毛利。業主原因的延誤（追加、等業主選料）請開追加減帳填「展延天數」讓業主簽認，完工日才會往後。

**10. 發包**（案場詳情 → 發包與估驗分頁 → 新增發包）
選工班、工種、工作範圍、金額。保留款％與保固金％會帶系統設定的預設值。
按「列印發包單」印出來給工班簽。

**11. 訂料**（案場詳情 → 建材訂料分頁）
品項、廠商、**現場需要日**、廠商回覆的交期。
交期晚於需要日的，系統會標紅並開待辦——工班撲空一天，那天的工資是白付的。

**12. 申請許可**（案場詳情 → 圖面與許可分頁）
室內裝修審查、消防圖說等。**有效期限要填**，到期前七天系統會開待辦。

**圖面**在同一個分頁上方：按「上傳新版圖面」，**圖名一樣就是同一張圖的新版本**，舊版自動退位。
發圖給工班後按「發布」登錄發給誰。圖名、分類、版次、業主可見打錯按「**編輯**」；
改圖名會連同這張圖的所有版本一起改。檔案本身不能換，要換就上傳新版。

### 階段三：施工中（每天在做的事）

**13. 看儀表板**（每日作業 → 營運儀表板）
「需要立刻處理」那一格每個數字都可以點，點進去就是該處理的那一頁。
每天早上花兩分鐘看完這一格，就不會有事情被忘記。

**14. 填工地日報**（每日作業 → 工地日報與照片 → 填今日日報）
日期、天氣、出工人數、今日進場工種、進度、現場狀況。
隔天補填也可以，日期改掉就好。

**15. 拍照存證**（同一頁 → 上傳照片）
**封板前的水電照、拆除前的原況照一定要拍。** 選階段（施工前／施工中／完工／隱蔽工程），
可以綁工序。勾「業主端看得到」的，業主從連結就看得到。
單檔 25MB、一次最多 20 張，接受 jpg／png／webp／heic／gif／pdf。

**16. 更新工進**（工進排程）
工序開工、完工就改狀態。改一道的日期，後面相依的工序會自動跟著推，
而且綁在那道工序上的請款節點會跟著觸發。

### 階段四：追加減帳（最會賠錢的環節）

**17. 現場一有變更，當下就開變更單**（合約與收款旁的追加減帳分頁 → 新增變更單）
事由、原因、逐項列出追加或減帳的品項與金額。可以帶「展延工期」。

**18. 按「送簽」**，然後二選一讓業主確認：
- **線上**：把業主端連結傳給他，他在手機上填姓名按確認。系統記下姓名、時間、來源 IP。
- **紙本**：按「列印變更單」印出來讓他簽，簽回來之後按「紙本回簽登錄」填是誰簽的。

**19. 簽認完成後**，金額才會併進合約總價與應收；有展延的話合約完工日自動往後。

> **未簽認的金額不會算進合約總價**，只會出現在「待簽認」那一格，
> 而且看起來像個未解決的問題——這是刻意的。送出超過三天沒簽，
> 系統每天會開一張待辦提醒你去追。
>
> 已簽認的變更單**不能修改也不能刪除**，要調整只能另開一張減帳單，
> 或整張作廢——軌跡才連得起來。

### 階段五：收錢與付錢

**收客戶的錢**（案場詳情 → 合約與收款分頁）

1. 節點變成「可請款」→ 按「**開單請款**」，填開單日與付款期限。
   **開單之後才算應收**，逾期才算得出來。沒開單的不算客戶欠，是自己卡住的錢。
2. 按「列印請款單」印出來，跟發票一起寄。
3. 錢進來 → 按「**登錄收款**」，選對應節點、填金額與發票號碼。
4. 追加款不在請款節點裡：登錄收款時「對應節點」**留空**即可。
5. 收款登錄錯了（日期、金額、發票號碼、對應節點）→ 收款紀錄那一列按「**編輯**」。
   改完之後節點是「已收足」還是「已請款」由系統重算，不用自己改狀態。

**付工班的錢**（發包單明細 → 估驗計價）

1. 按「新增一期估驗」，填**累計完成％**（不是本期％）。
   本期金額由系統用「累計 − 前期累計」算出來，所以**不可能重複計價**。
2. 系統自動扣保留款與保固金。如果這個工班有勾「向工班求償」的缺失，
   可以在同一張估驗單勾選一併扣款，而且**扣過就不會被扣第二次**。
3. 估驗單確認後進「應付與押款」頁 → 實際付款後按「登錄付款」。
   **個人工班**（工班資料的「請款身分」選「個人」）會自動代扣所得稅與二代健保補充保費：
   「應付」是欠工班的錢，「實匯」才是要匯出去的錢，「代扣」由公司申報繳納。退保留款、保固金時也一樣代扣。
   預設依執行業務所得：單次給付超過 2 萬元扣所得稅 10%、達 2 萬元扣補充保費 2.11%，
   比例與門檻在「系統設定 → 契約與代扣」可以改。**工班報酬屬於哪一類所得請跟會計師確認。**
4. 工班完工、保留款還押著的話，系統會提醒你辦理退還——
   這關係到下一次還找不找得到人。
5. 發包明細打錯 → 明細那一列按「**編輯**」，發包總價自動重算。
   **改完的總價不能低於已估驗金額**，否則會被擋下來。
6. 估驗打錯（％、期別、其他扣款）→ 按那一期的「**編輯**」，本期金額、保留款、保固金、實付照新的累計％整個重算。
   只有**最後一期、還沒付款**的可以改；已經扣回的缺失求償會維持扣在那一期。
   前面某一期錯了，要從最後一期往回刪到那一期再重做——中間某期一改，後面各期的本期金額就全錯了。

**跨案看錢**：
- 應收帳款頁分三段，因為要做的事不一樣：**可請款未開單**（去開單）、
  **已請款未收**（去催）、**已簽追加未收**（最常整筆被忘掉的一段）。
- 應付與押款頁：已確認待付的估驗單、各工班押著的保留款與保固金。

### 階段六：驗收與交屋

**20. 點交列缺失**（交屋 → 缺失與驗收 → 新增缺失）
位置、項目、責任工班、要求改善日。
**每一筆缺失都可以附照片**——點交當下拍一張，改善完再拍一張，
複驗與向工班求償靠的就是這兩張。

**21. 要向工班求償的**，勾「向工班求償」並填改善成本，
下次估驗計價時就可以直接勾選一併扣款。

**22. 改善完成 → 複驗通過**，狀態改「複驗通過」。

**23. 填交屋日**（案場詳情 → 編輯案場 → 交屋日）
保固從這一天起算。

**24. 建保固項目**（交屋 → 保固維修，或案場的缺失與保固分頁）
防水、木作、五金等各自的保固月數。到期前 30 天系統會開待辦提醒你主動回訪——
**現在修是服務，過期再修是爭議。**

**25. 業主報修**：在保固頁按「報修」，直接轉成一張缺失單進入追蹤清單。

### 階段七：結案

**26. 看損益**（經營 → 專案損益）
合約總價 vs 已發包＋建材＋雜支，以及「超出估價多少」。
點「**成本結構**」可以往下看錢是花在哪個工種、哪家廠商、哪個雜支科目——
這是下次報價要調哪裡的依據。

**27. 案場狀態改「已結案」。**

## 業主端怎麼用

**產生連結**：案場詳情 → 上方「業主端連結」→ 產生。複製那條網址傳給業主（LINE 即可）。
**不需要帳號密碼**，業主點開就看得到。

業主看得到：工程進度（總進度與逐道工序）、付款階段與已付金額、
**變更單線上簽認**、現場照片（勾了業主可見的）、施工日誌、設計圖面（勾了業主可見的現行版本）、
以及一個「反映問題」的表單——他填的會直接進公司的缺失追蹤清單。

業主看不到：成本、發包金額、工班資料、毛利。

**覺得連結外流就重新產生一次，舊連結立刻失效。**

> 注意：照片與圖面的檔案本身是靠不可猜的亂數檔名保護（因為業主端沒有帳號）。
> 「業主可見」控制的是**列不列出來**，不是擋不擋得住——
> 檔案網址如果被轉傳出去，拿到的人就看得到。

## 系統每天自己會做的事

每六小時跑一次，你不用管它。內容是資料庫備份（保留 14 份，另存異地一份）、
操作紀錄清理，以及這八種提醒——**同一件事不會每天洗出一張新待辦**：

1. 工進到了請款節點 → 節點轉「可請款」並開待辦
2. 已請款逾期未收 → 催收
3. 變更單送出三天沒簽 → 催簽
4. 建材交期晚於現場需要日，或需要日到了還沒下單
5. 許可將到期（預設七天內）
6. 缺失逾期未改善
7. 保固到期前 30 天 → 主動回訪
8. 工班已完工但保留款還押著 → 辦理退還

## 常見狀況怎麼處理

| 狀況 | 怎麼做 |
| --- | --- |
| 客戶在工地口頭說要加東西 | **當下就開變更單並送簽**，不要等。沒簽認的施作，結算時收不到錢 |
| 已簽認的變更單金額打錯 | 不能改。另開一張減帳單沖掉，或整張作廢後重開 |
| 工班說做了七成，上期報過六成 | 估驗填**累計 70%**，系統自己算本期 10%。不要填 10% |
| 客戶說沒收到請款單 | 應收帳款頁看是不是「可請款未開單」——那代表單根本還沒開 |
| 想知道這個案子還賺不賺 | 專案損益頁 →「超出估價」那欄比毛利率準（前期還沒發包的工種不在成本裡） |
| 工班一直來要保留款 | 應付與押款頁看押了多少；發包單明細裡按「退保留款」登錄 |
| 找不到某張單 | 每一頁的「搜尋」吃單號、名稱、案場、業主；找不到就把狀態篩選清掉再找一次。選案場的頁面先確認左邊選對案場 |
| 找幾個月前的日報或照片 | 工地日報與照片 → 上方填日期範圍。沒篩選時只列最近 30 份日報、60 張照片 |
| 收款金額或日期登錄錯了 | 請款與收款 → 收款紀錄那一列按「編輯」，節點狀態會自動重算 |
| 估驗的累計％填錯 | 最後一期且未付款：按「編輯」改％。已付款的不能改，差額在下一期估驗時補正 |
| 變更單明細打錯 | 還沒簽認：打開變更單，明細那一列按「編輯」。已簽認的見上一列「金額打錯」的做法 |
| 圖面名稱或版次打錯 | 圖面與許可 → 那一列按「編輯」 |
| 要給會計一份資料 | 每張清單與報表都有「**匯出 CSV**」按鈕，匯出的就是畫面上篩選後的結果 |
| 某個人離職 | 系統 → 帳號權限 → 刪除。做過事的會自動改成停用，歷史紀錄保留 |
| 想知道是誰改的 | 系統 → 操作紀錄，可依人員、身分（員工／業主端）、日期範圍查 |

## 每個角色每天／每週要看什麼

**負責人**
- 每天：營運儀表板的「需要立刻處理」
- 每週：應收帳款（三段都看）、專案損益（看「超出估價」）
- 每月：應付與押款（確認押著的錢有沒有該退的）

**設計師**
- 每天：我的工作、追加減帳（有沒有送出沒簽的）
- 每週：自己案子的工進與請款節點

**工務**
- 每天：填工地日報、拍照、更新工序狀態
- 每週：建材交期（有沒有來不及的）、缺失改善進度

**會計／行政**
- 每天：應收帳款「已請款未收」
- 每週：應付與押款的待付估驗單
